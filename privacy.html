Политика конфиденциальности

Personal Job Search — личное некоммерческое приложение для поиска работы. Обновлено: 13 ноября 2026.

Какие данные доступны

Приложение использует Google OAuth с разрешением https://www.googleapis.com/auth/gmail.readonly. Технически это разрешение предоставляет доступ на чтение писем подключённого аккаунта Gmail. Программа выбирает и обрабатывает письма с уведомлениями о вакансиях и необходимые служебные заголовки.

Хабр Карьера

В приложении используются открытые RSS-записи о вакансиях Хабр Карьеры: название, опубликованная дата, публичная ссылка и краткие сведения. Доступ к аккаунту Хабр Карьеры и его API не подключён. В будущем, если владелец отдельно разрешит OAuth-доступ и площадка активирует приложение, допускается чтение разрешённых сведений о вакансиях только в пределах документированных методов API; автоматическая отправка откликов и изменение аккаунта не предусмотрены. Секреты не публикуются.

Цель обработки

Из подходящих уведомлений извлекаются ссылки и ограниченные данные для личного отчёта о вакансиях. Данные Gmail не используются для рекламы, торговли пользовательскими данными или профилирования других людей.

Хранение и безопасность

OAuth-ключи сохраняются в GitHub Actions Secrets приватного репозитория. История открытых идентификаторов вакансий и статусов проверки хранится в приватном репозитории GitHub. Временные технические отчёты сохраняются как закрытые артефакты GitHub Actions не дольше семи дней. Полные тексты писем и OAuth-ключи не публикуются в этом публичном репозитории.

Передача

Приложение не продаёт данные Google и не предоставляет доступ рекламодателям или посторонним пользователям. Для запуска программы и хранения технической истории используется инфраструктура GitHub. Содержимое личных писем не передаётся в AI-сервис для анализа.

Контроль и удаление

Владелец может отозвать доступ приложения в настройках своего аккаунта Google, а также удалить историю и отчёты из приватного GitHub-репозитория. После отзыва доступа программа не может читать новые письма.

Условия Google

Использование Google API регулируется Google API Services User Data Policy, включая Limited Use.
