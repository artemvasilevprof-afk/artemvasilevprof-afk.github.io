# ROLF — интерактивный прототип, блоки 1–3

Источник дизайна: Figma, секция «верстка», node 324:312.

## Что реализовано

- Блок 1: главный экран с ROLF и меню, затем чёрная секция перекрывает его при прокрутке.
- Блок 2: закреплённая сцена на четыре этапа: Innovation, Qualität, Produktion, Support.
- Текст заголовков плавно появляется; описание раскрывается построчно по мере прокрутки.
- Индикатор прогресса из четырёх сегментов заполняется синхронно со скроллом.
- Четыре оригинальных изображения масла из макета Figma плавно переходят друг в друга. Это не физическая 3D-симуляция.
- Блок 3: обычная прокрутка, четыре преимущества появляются последовательно.
- Базовая адаптация для мобильной ширины.

## Ограничения

Это тест механики, не финальный production-сайт. Дизайн ниже блока 3 не включён. Переливание масла имитируется переходами между исходными кадрами, без готовой видеоанимации. DIN Pro может заменяться системным шрифтом, если он не установлен у пользователя.
