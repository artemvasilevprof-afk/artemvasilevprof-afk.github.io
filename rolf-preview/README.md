# ROLF — интерактивный прототип, блоки 1–3

Источник дизайна: Figma, секция «верстка», node 324:312.

## Блок 1
- Первый экран с ROLF, навигацией и переходами.

## Блок 2
- Закреплённая сцена на четыре этапа: Innovation, Qualität, Produktion, Support.
- При входе в секцию сначала появляются четыре линии прогресса, затем подписи.
- После короткой вступительной паузы автоматически появляются заголовок, описание и первое изображение масла.
- Описание раскрывается построчно.
- Прогресс каждой линии заполняется по прокрутке.
- После заполнения линии предусмотрен дополнительный участок прокрутки около 150 px: текущая линия остаётся заполненной, а текст и изображение переходят к следующему состоянию.
- После переходного участка начинается заполнение следующей линии.
- Переходы работают в обе стороны.
- Важное исправление: больше нет блокировки колёсика, принудительной коррекции scroll offset и таймерного «перескакивания» страницы. Пауза реализована как обычный участок прокрутки внутри закреплённой секции.
- Четыре оригинальных изображения масла из Figma плавно сменяют друг друга. Это переходы между кадрами, не физическая 3D-симуляция.

## Блок 3
- Номер и заголовок карточки появляются слева.
- Описание раскрывается последовательно, строка за строкой.
- Анимация запускается при входе секции в область видимости.

## Общие детали
- Плавная прокрутка колёсиком мыши через Lenis; сенсорный скролл остаётся нативным.
- Базовая адаптация для мобильной ширины.
- При настройке prefers-reduced-motion анимации не навязываются.

## Ограничения

Это тест механики, не production-сайт. Контент ниже блока 3 не включён. Масло пока переключается между четырьмя исходными изображениями, без отдельной видеоанимации или морфинга формы. DIN Pro может заменяться системным шрифтом, если он не установлен у пользователя.
