# ROLF — интерактивный прототип, блоки 1–3

Источник дизайна: Figma, секция «верстка», node 324:312.

## Что реализовано

- Блок 1: первый экран с ROLF, навигацией и переходами.
- Блок 2: закреплённая сцена на четыре этапа: Innovation, Qualität, Produktion, Support.
- При появлении чёрной сцены сначала проявляются четыре линии прогресса, затем подписи.
- После этого автоматически появляются заголовок, описание и первое изображение масла — без дополнительного скролла.
- Описание раскрывается построчно.
- Прогресс каждой линии заполняется по прокрутке.
- На завершении каждого этапа прокрутка делает короткую паузу: текст и изображение переходят к следующему состоянию, затем скролл продолжается.
- Паузы работают и при обратной прокрутке: можно возвращаться к предыдущим состояниям.
- Четыре оригинальных изображения масла из Figma плавно сменяют друг друга. Это переходы между кадрами, не физическая 3D-симуляция.
- Плавная прокрутка страницы реализована через Lenis; для пользователей с настройкой reduced motion анимации отключаются.
- Блок 3: четыре преимущества. Номер и заголовок появляются слева, описание — построчно.
- Есть базовая адаптация для мобильной ширины.

## Ограничения

Это тест механики, не production-сайт. Контент ниже блока 3 не включён. Масло пока переключается между четырьмя исходными изображениями, без отдельной видеоанимации или морфинга формы. DIN Pro может заменяться системным шрифтом, если он не установлен у пользователя.
