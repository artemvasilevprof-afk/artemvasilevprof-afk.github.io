ЧАСТНЫЙ НЕКОММЕРЧЕСКИЙ ПРОЕКТ

Personal Job Search

Персональное приложение для автоматизации поиска вакансий, используемое одним владельцем. Оно собирает уведомления о вакансиях, получает открытые описания через официальные разрешённые источники, фильтрует предложения и формирует личные отчёты.

Функции

  • Чтение уведомлений о вакансиях через Google Gmail API с разрешением gmail.readonly.
  • Извлечение открытых ссылок на вакансии и предварительная проверка условий работы.
  • Хранение технической истории обнаружения публичных вакансий для исключения дублей.
  • Подготовка подборок и черновиков сопроводительных писем без отправки откликов.

Приложение не предоставляет публичного доступа и не используется для коммерческого рекрутинга.
